# DRILL 9 - 소년 상하좌우 이동 및 방향 바꾸기

2D 게임 프로그래밍 (LEC10 입력 처리) Drill #9

## 실행

```
pip install pico2d
python move_boy.py
```

| 키 | 동작 |
| --- | --- |
| 방향키 | 상하좌우 이동 (두 키를 함께 누르면 대각선) |
| I | 정보 표시(동작 이름, 좌표) 켜고 끄기 |
| ESC / 창 닫기 | 종료 |

## 파일

| 파일 | 설명 |
| --- | --- |
| `move_boy.py` | 게임 소스 |
| `animation_sheet.png` | 소년 스프라이트 시트 (100x100 프레임 8개 x 4줄) |
| `TUK_GROUND.png` | 배경 (1280x1024, 캔버스 크기도 이에 맞춤) |
| `test_move_boy.py` | 자동 테스트 (`python test_move_boy.py`, 창이 잠깐 떴다 닫힘) |

이미지는 상대경로로 읽고, 실행 시 작업 폴더를 소스 폴더로 옮기므로 어느 폴더에서 실행해도 된다.

## 채점 기준과 구현

| 기준 | 구현 |
| --- | --- |
| 상하좌우 이동 (3점) | `KEYDOWN` 이면 `dir_x`/`dir_y` 에 +-1, `KEYUP` 이면 되돌린다 (수업의 `dir` 방식). `update` 에서 매 프레임 그 방향으로 이동해 키를 누르고 있는 동안 계속 움직인다. 대각선도 같은 속도 |
| IDLE 애니메이션 (1점) | 움직이지 않으면 마지막으로 바라본 방향의 IDLE 줄을 재생한다 |
| 화면경계면 벗어나지 않음 (1점) | 시트에서 잰 실제 그림 크기(중심에서 좌32/우34/하39/상41)만큼 여백을 두고 `clamp` 해서 화면 끝까지 가되 넘지 않는다 |
| 이동 애니메이션 | 좌우 이동은 그 방향 달리기, 위아래 이동은 기존 방향을 유지한 채 달리기 |

## 시트 구성 (pico2d 좌하단 원점 기준 bottom)

| bottom | 동작 |
| --- | --- |
| 300 | IDLE 오른쪽 |
| 200 | IDLE 왼쪽 |
| 100 | 달리기 오른쪽 |
| 0 | 달리기 왼쪽 |
