# PRD: Sonic 애니메이션 뷰어

## 1. 목표

`sonic-sprite.png` 에 들어 있는 소닉의 모든 동작을 pico2d 창에서 차례대로, 끝없이 재생한다.
한꺼번에 만들지 않고 작은 단계로 나눠 개발하며, 단계마다 커밋해 최소 20회 커밋을 남긴다. **커밋 메시지는 반드시 한글로 작성한다.**

## 4. 스프라이트 시트 분석

### 4.1 시트 구조

- 동작이 가로 한 줄씩 놓여 있고, 줄은 위에서 아래로 10개다. 단 8번 줄과 10번 줄에는 각각 동작 2개가 들어 있다.
- 프레임마다 **폭, 높이, 간격이 다르다.** 그래서 "프레임 폭 x 번호" 같은 계산으로는 자를 수 없고, 프레임마다 좌표를 따로 적어야 한다.
- 배경이 이미 투명해서 배경 제거 작업은 필요 없다.

### 4.2 동작 목록 (19단계 검수로 확정)

투명하지 않은 픽셀 기준으로 구한 줄별 범위다. 1차 분석은 검은 외곽선 픽셀을 빼고 세어서 3, 7, 8, 10번 줄이 1px 짧았고, 19단계에서 바로잡았다.

| 줄 | 이미지 y 범위 (위 기준) | pico2d 바닥 (`bottom`) | 높이 | 프레임 수 | 동작 이름 (임시)                |
| -- | ----------------------- | ------------------------ | ---- | --------- | ------------------------------- |
| 1  | 39 ~ 77                 | 447                      | 39   | 11        | IDLE (서기·대기)               |
| 2  | 79 ~ 117                | 407                      | 39   | 12        | WALK (걷기 → 달리기)           |
| 3  | 121 ~ 163               | 361                      | 43   | 6         | SKID (브레이크·미끄러짐)       |
| 4  | 167 ~ 199               | 325                      | 33   | 9         | SPIN (스핀 대시)                |
| 5  | 206 ~ 232               | 292                      | 27   | 6         | ROLL (공 구르기)                |
| 6  | 238 ~ 273               | 251                      | 36   | 6         | DASH (빠른 달리기)              |
| 7  | 283 ~ 317               | 207                      | 35   | 6         | PEEL (8자 다리 달리기)          |
| 8  | 326 ~ 370 (HURT 341 ~ 368) | 154 (HURT 156)        | 45 (HURT 28) | 6 + 2 | TURN (뒤돌기) 6 + HURT (피격) 2 |
| 9  | 377 ~ 416               | 108                      | 40   | 8         | PUSH (밀기 등)                  |
| 10 | 426 ~ 468 (WAVE 427 ~ 465) | 56 (WAVE 59)          | 43 (WAVE 39) | 2 + 2 | RAISE (두 팔 들기) 2 + WAVE (손 흔들기) 2 |

합계 76프레임, 동작 12개 (8번 줄을 TURN 과 HURT 로, 10번 줄을 RAISE 와 WAVE 로 나눔).

### 4.3 좌표 변환

이미지 편집기와 분석 결과의 y 는 **위쪽이 0** 이고, pico2d 는 **아래쪽이 0** 이다.

```
bottom = 525 - (이미지에서 프레임 아래쪽 y) - 1
```

예) 1번 줄 아래쪽 y = 77 → `bottom = 525 - 77 - 1 = 447`

| 줄 | 문제                                                      | 처리                                               |
| -- | --------------------------------------------------------- | -------------------------------------------------- |
| 1  | 세로줄 기준으로 보면 프레임 2~3개가 붙어 보임              | 픽셀이 이어진 덩어리 기준으로 나누니 11개로 깔끔히 나뉨 |
| 8  | 앞→뒤로 도는 프레임 6개 뒤에 피격 프레임 2개가 붙어 있음 | 앞 6개는 TURN, 뒤 2개(x 184 부터)는 HURT 로 나눈다. HURT 는 줄 아래쪽보다 떠 있어 자기 범위(y 341~368)로 자른다 |
| 10 | 두 팔을 드는 프레임 2개 뒤에 한 손을 흔드는 프레임 2개가 붙어 있음 | 앞 2개는 RAISE, 뒤 2개(x 96 부터)는 WAVE 로 나눈다. WAVE 는 발이 3px 높아 자기 범위(y 427~465)로 자른다 |

## 5. 설계

### 5.1 화면 배치

```
y=800 ┌──────────────────────────────┐
      │  WALK 3/5         (y≈770)    │  ← 동작 이름, 반복 횟수
      │                              │
      │           ┌──────┐           │
      │           │ 소닉 │  x4 확대   │  ← 가로 가운데 (x=600)
      │           └──────┘           │
      │ ──────────────────── (y=300) │  ← 바닥선: 모든 프레임의 발끝
y=0   └──────────────────────────────┘
```

- 4배 확대 시 가장 넓은 프레임은 HURT 160px, 가장 높은 프레임은 TURN 180px 이다. 바닥선 y=300 에 세우면 위끝이 480 이라 글자(y≈770)와 겹치지 않는다.
- 프레임 높이가 달라도 발이 흔들리지 않도록, 그릴 때 중심 y 를 `바닥선 + (프레임 높이 x SCALE) / 2` 로 계산한다.

### 5.2 데이터 구조

동작 하나를 `(이름, 프레임 시간, 이동 속도, 프레임 목록)` 으로, 프레임 하나를 `(left, bottom, w, h)` 로 적는다.
이동 속도는 **원본 픽셀/초** 단위로 적고, 그릴 때 `SCALE` 을 곱한다. 0 이면 제자리, 음수면 왼쪽으로 이동한다.

```python
ANIMATIONS = [
    ('IDLE', 0.15, 0, [(1, 447, 29, 39), (31, 447, 26, 39), ...]),
    ('WALK', 0.07, 60, [(8, 407, 26, 39), ...]),
    ...
]
```

### 5.3 재생 상태

| 변수             | 뜻                                           |
| ---------------- | -------------------------------------------- |
| `anim_index`   | 지금 재생 중인 동작 번호 (0 ~ 11)            |
| `frame_index`  | 그 동작 안의 프레임 번호                     |
| `repeat_count` | 지금까지 반복한 횟수 (0 ~ 5)                 |
| `paused`       | 1초 쉬는 중인지                              |
| `elapsed`      | 현재 프레임(또는 쉬기)이 시작된 뒤 지난 시간 |
| `x`            | 캐릭터의 화면 x (0 ~ 1200). 동작이 바뀔 때 `600 - 5회 이동 거리` 에서 출발한다 |

상태는 아래 순서로 바뀐다.

```
[재생] 프레임 시간마다 다음 프레임, 동시에 x += 이동 속도 x SCALE x 지난 시간
   │  마지막 프레임을 지나면 repeat_count + 1, frame_index 는 0 으로
   │  단 repeat_count == 5 가 되면 frame_index 를 0 으로 되돌리지 않고
   ▼
[쉬기] 마지막 프레임을 1초 유지 (이동도 멈춤)
   │  1초가 지나면
   ▼
다음 동작으로 (anim_index + 1, 12 이면 0) → repeat_count, frame_index 를 0 으로, x 를 출발 위치로 → [재생]
```

### 5.4 시간 처리

- 프레임 전환과 1초 쉬기는 **루프 횟수가 아니라 실제 경과 시간**(`get_time()`)으로 잰다. 컴퓨터가 빠르든 느리든 같은 빠르기로 재생된다.
- 프레임 1장 표시 시간은 처음엔 모두 0.1초로 만들고(1~22단계), 2차 요구사항(F10)에서 동작마다 다르게 바꾼다.
- 이동은 루프마다 **지난 시간 x 속도** 만큼 x 를 늘린다. 프레임 전환과 같은 시간 기준이라 애니메이션과 이동이 함께 맞는다.
- 전체 한 바퀴 시간: 동작마다 (프레임 수 x 프레임 시간 x 5회) 의 합 + 1초 x 12동작 = 33.9 + 12 ≈ **46초** (5.6 표 기준)

### 5.5 상수

| 상수                       | 값                               | 용도                                     |
| -------------------------- | -------------------------------- | ---------------------------------------- |
| `CANVAS_W`, `CANVAS_H` | 1200, 800                        | 화면 크기                                |
| `SCALE`                  | 4                                | 확대 배율                                |
| `REPEAT`                 | 5                                | 동작별 반복 횟수                         |
| `PAUSE_TIME`             | 1.0                              | 반복 뒤 쉬는 시간(초)                    |
| `GROUND_Y`               | 300                              | 바닥선 y                                 |
| `FONT_PATH`              | `C:/Windows/Fonts/consola.ttf` | 글자 표시용 글꼴 (`load_font` 에 필요) |

프레임 시간은 동작마다 달라서 상수가 아니라 `ANIMATIONS` 표에 넣는다 (5.6).

### 5.6 동작별 프레임 시간과 이동 속도 (2차 요구사항)

| 동작 | 프레임 | 프레임 시간(초) | 1회 재생 | 이동 속도 (원본 px/초 → 화면 px/초) | 이유 |
| --- | --- | --- | --- | --- | --- |
| IDLE | 11 | 0.15 | 1.65초 | 0 (제자리) | 서서 기다리는 동작이라 느리게 |
| WALK | 12 | 0.07 | 0.84초 | 60 → 240 | 걷기에서 달리기로 이어지는 보통 빠르기 |
| SKID | 6 | 0.08 | 0.48초 | 30 → 120 | 브레이크를 걸며 미끄러지므로 느리게 앞으로 |
| SPIN | 9 | 0.05 | 0.45초 | 0 (제자리) | 제자리에서 몸을 말아 회전, 빠르게 |
| ROLL | 6 | 0.04 | 0.24초 | 150 → 600 | 공이 되어 굴러가므로 빠르게 |
| DASH | 6 | 0.05 | 0.30초 | 120 → 480 | 빠른 달리기 |
| PEEL | 6 | 0.04 | 0.24초 | 180 → 720 | 8자 다리, 가장 빠른 달리기 |
| TURN | 6 | 0.12 | 0.72초 | 0 (제자리) | 몸을 천천히 돌리는 동작 |
| HURT | 2 | 0.15 | 0.30초 | 40 → 160 | 맞고 오른쪽으로 날아감 (처음엔 왼쪽 -40 으로 정했다가 요청으로 변경) |
| PUSH | 8 | 0.12 | 0.96초 | 15 → 60 | 무언가를 밀며 천천히 앞으로 |
| RAISE | 2 | 0.15 | 0.30초 | 0 (제자리) | 두 팔을 드는 동작, 느리게 |
| WAVE | 2 | 0.15 | 0.30초 | 0 (제자리) | 손을 흔드는 동작, 느리게 |

- 값은 실행해 보며 발이 미끄러져 보이지 않도록 조정할 수 있다. 조정하면 이 표도 함께 고친다.
- 5회 반복 동안의 이동 거리는 가장 긴 WALK 가 약 1000px 로, 화면을 한 번 정도 가로지른다.
- 가운데에서 출발하면 ROLL, DASH 는 화면 밖에서 5회를 마쳐 쉬는 모습이 안 보였다. 그래서 출발 위치를 `600 - 이동 거리` 로 거꾸로 계산한다.

## 7. 완료 기준

- [ ] 12개 동작이 모두 한 번씩 나온다
- [ ] 동작마다 5회 반복 → 1초 쉬기 → 다음 동작 순서가 지켜진다
- [ ] 12번째 동작(WAVE) 뒤에 1번째 동작(IDLE)이 다시 나온다
- [ ] 이웃 프레임이 섞이거나 몸이 잘린 프레임이 없다
- [ ] 동작이 바뀌어도 캐릭터가 위아래로 튀지 않는다
- [ ] 화면 표시 글자가 실제 반복 횟수와 맞다
- [ ] ESC 와 창 닫기로 정상 종료된다
- [ ] 동작마다 프레임 시간이 5.6 표대로 다르다
- [ ] 이동 동작은 애니메이션과 함께 움직이고, 제자리 동작과 쉬는 1초 동안은 움직이지 않는다
- [ ] 화면 끝에 걸친 몸의 잘린 부분이 반대쪽 끝에 바로 보인다
- [ ] 모든 동작이 1초 동안 화면 가운데에서 쉰다
- [ ] `git log --oneline` 기준 이 기능 커밋이 20회 이상이고, 메시지가 모두 한글이다
